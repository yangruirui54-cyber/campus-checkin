# NadPass · 校园参与护照

**把一次活动参与，变成可以查询、可以撤销的记录。**

[打开交互演示](https://yangruirui54-cyber.github.io/campus-checkin/) · [Solidity 合约](contracts/NadPass.sol) · [90 秒演示脚本](DEMO.md)

NadPass 是一个校园参与记录应用，让组织者签发凭证、参与者收藏经历、验证者查询记录。适用于工作坊、社团共学与校园协作，包含网页界面、Solidity 登记合约和钱包交互。

> **当前版本：交互原型。** 支持本地演示与合约部署流程，尚未部署到 Monad 测试网。演示中的活动与凭证为示例数据。

![NadPass 交互界面](docs/preview.png)

## 为什么做这个

活动结束后，参与记录常留在不同表格或群聊里，展示和核对不方便。NadPass 让活动方签发记录，参与者集中查看，第三方查询是否有效。误发的记录可以撤销，查询者看到的是最新状态。

链上记录提供跨应用可查询的签发状态，但**不能证明真实到场、活动方的现实身份或参与者的能力**。验证者仍需确认签发地址值得信任。小型内部活动使用普通数据库可能更便宜、更合适；这里是对公开凭证的一次技术探索。

## 产品流程

1. **发现活动**：按名称或编号搜索，筛选开放或已关闭的活动，查看活动方、名额和状态。
2. **活动工作台**：创建、关闭活动，签发或撤销凭证；分页查看签发记录并导出当前页 CSV。
3. **我的护照**：按有效或已撤销筛选凭证，导出带来源标记的 JSON。
4. **验证凭证**：按活动编号与钱包地址查询状态。

| 能力 | 本地演示 | 测试网模式 |
| --- | --- | --- |
| 数据来源 | 本机 localStorage，可重置 | 当前连接的合约 |
| 身份 | 固定示例地址，模拟活动方 | 浏览器钱包 |
| 创建 / 签发 / 撤销 | 本地操作，无交易 | 用户钱包确认交易 |
| 权限 | 演示流程 | 合约检查活动创建者 |
| 验证 | 本机数据，不是链上验证 | 读取合约签发与撤销状态 |

凭证是不可转移的登记记录，**没有实现 ERC-721 / ERC-1155，也不声称是标准 NFT**。不包含代币或交易功能。

## 本地运行

仓库包含已构建网页，无需安装 Node 依赖即可体验：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765/docs/ 。请通过 HTTP 打开，不要直接双击 HTML。

修改代码、构建与测试（Node.js 20+）：

```sh
npm ci
npm run build
npm test
```

浏览器测试需要上面的本地服务与 Microsoft Edge：

```sh
npm run test:ui
npm run test:management
node tests/ui-chain.mjs
```

## 试用 Monad 测试网

页面右上角「连接测试网」→ 连接浏览器钱包 → 部署自己的测试合约或输入可信的 NadPass 合约地址。需要测试网 MON，交易须由钱包确认。只有活动创建者能签发、撤销或关闭自己的活动。

Chain ID `10143`，RPC `https://testnet-rpc.monad.xyz`。使用前可对照 [Monad 官方测试网文档](https://docs.monad.xyz/developer-essentials/testnet) 与 [官方水龙头](https://faucet.monad.xyz)。应用不请求或保存私钥和助记词。

新部署合约的版本为 `NadPass/2`，支持每次最多 50 个地址的分页查询。网页记录列表每页显示 10 条。既有 `NadPass/1` 合约仍可连接、签发和逐地址验证，但不支持记录列表。

ABI 与字节码由 `solc 0.8.30` 构建，EVM 目标为 `paris`。部署后可通过合约地址查询实际记录。

## 合约规则

- 每场活动由创建者管理；其他地址不能签发、撤销或关闭该活动。
- 同一活动同一地址最多获得一次凭证，撤销后不能重发。
- 名额按累计签发计算，撤销不释放名额；每场最多 500 个名额。
- 关闭后停止签发，已有记录仍可查询和撤销。
- 校验空名称、超长名称、无效名额与零地址。
- 事件日志记录创建、签发、撤销。
- 分页记录按签发顺序返回；撤销不会移除历史记录。

## 限制与取舍

当前合约未经过安全审计，没有现实身份认证、防冒名到场机制、索引服务或生产运维。创建者仍可能错误签发。测试网模式只加载最近 50 场活动，较早活动可用编号验证。导出 JSON 不是密码学签名证明，需要回到原合约核验。链上活动名和钱包关系公开，不应填写姓名、学号等个人资料。切换钱包账户或网络会退回本地模式，需重新连接。
